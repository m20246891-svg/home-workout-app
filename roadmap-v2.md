## Модель данных (БЛОЧНАЯ) — src/data/workouts.json

Ключевое изменение: тренировка состоит из блоков, блок повторяется N раз,
элементы блока — упражнения (на время/повторы) и отдых. Всё время в СЕКУНДАХ.

          "equipment": "none",
          "coverImage": "",
          "description": "Короткая тренировка на всё тело без инвентаря.",
          "blocks": [

              "repeat": 1,
              "items": [
                { "type": "exercise", "exerciseId": "jumping-jacks",

      "instructions": "Прыжком расставь ноги и подними руки над головой, вернись обратно."

Заметки к модели:
- Упражнения вынесены в отдельный справочник `exercises` (по id), чтобы не дублировать
  инструкции — одно упражнение используется в разных тренировках.
- `mode`: "timed" (durationSec) или "reps" (reps).
- `equipment`: "none" / "dumbbells" / "mat" — под простой фильтр (2-3 варианта).
- `repeat` у блока — сколько раз повторить его целиком (видели 1x/2x/3x).
- Поля coverImage/note — опциональные.

## Спецификация плеера выполнения (сердце MVP)
Референс: design-reference/trenirovki-doma/workout-player-*.png

Поток при нажатии «Начать» на детальной тренировке:
1. Приложение «разворачивает» блоки в плоскую последовательность шагов с учётом repeat.
   Пример: main с repeat=2 → все items блока идут дважды подряд.
2. Отсчёт «Приготовьтесь 3-2-1» перед первым упражнением.
3. Для каждого шага:
   - если это упражнение mode="timed" → ExercisePlayer: название, инструкция,
     крупный таймер обратного отсчёта, прогресс «Упражнение N/всего», пауза, «пропустить/дальше».
   - если mode="reps" → ExercisePlayer: название, инструкция, число повторов,
     кнопка «Готово» для перехода (таймера нет).
   - если это rest → RestScreen: «ОТДЫХ», таймер, кнопки «+20 сек» и «Пропустить»,
     превью следующего упражнения.
4. После последнего шага → WorkoutComplete: поздравление, сохранение в localStorage,
   пересчёт streak, показ текущей серии. Бейдж за первую тренировку (опционально).

Упрощения против референсов (осознанные): только портрет (без landscape),
выход по простому «Выйти/Продолжить» (без опроса причин), без push, без целей серии.

## Этап 1 — Данные (блочная модель) + каталог
```
Прочитай design-reference/README.md (раздел про блочную модель) и notes.md в папках
nike-training-club и trenirovki-doma (экраны каталога и детальной тренировки).

1. Создай src/data/workouts.json по БЛОЧНОЙ модели: категории → тренировки → blocks
   (Разминка/Основная/Заминка, у блока repeat) → items (type "exercise" с mode
   "timed"/"reps", либо type "rest"). Упражнения вынеси в отдельный справочник exercises
   по id (name + instructions на русском). Время — в секундах. Поле equipment:
   none/dumbbells/mat. Заполни минимум 3 категории (например «Всё тело», «Кардио/ВИИТ»,
   «Растяжка») по 2 тренировки в каждой, с реалистичными упражнениями и короткими
   инструкциями по технике.

2. Свёрстай страницу Workouts.jsx (маршрут /workouts): шапка с местом под индикатор
   серии, быстрый выбор по уровню (Новичок/Продолжающий/Продвинутый) как фильтр,
   категории со списком карточек. Вынеси карточку тренировки в компонент WorkoutCard.jsx
   (превью-заглушка, название, длительность, уровень). Данные — только из workouts.json.

Ориентируйся на макеты каталога из notes.md, но упрощай: без поиска, без ИИ, без программ.
```

## Этап 2 — Детальная тренировка + плеер выполнения
```
Прочитай в README.md разделы «Спецификация плеера выполнения» и «Модель данных».
Референс-скрины: design-reference/trenirovki-doma/workout-player-*.png (главный образец).

1. WorkoutDetail.jsx (/workout/:id): метаданные тренировки (время, уровень, инвентарь),
   описание, список блоков с упражнениями (название, дозировка: «30 сек» или «15 повт.»,
   отдых отдельной строкой), кнопка «Начать» → /workout/:id/play.

2. WorkoutPlayer.jsx (/workout/:id/play): разверни блоки в плоскую последовательность
   шагов с учётом repeat. Отсчёт «Приготовьтесь 3-2-1». Затем по шагам:
   - ExercisePlayer.jsx для упражнений: mode "timed" — крупный таймер обратного отсчёта
     с паузой; mode "reps" — число повторов и кнопка «Готово». Показывай название,
     инструкцию из справочника exercises, прогресс «Упражнение N из M», кнопку «Дальше».
   - RestScreen.jsx для отдыха: заголовок «Отдых», таймер, кнопки «+20 сек» и «Пропустить»,
     превью следующего упражнения.
   Выход из тренировки — простое подтверждение «Выйти/Продолжить».
   После последнего шага — переход на экран завершения (заглушка, логику добавим в Этапе 3).

Только вертикальная ориентация. Вся логика таймеров — на чистом React state,
без внешних библиотек.
```

## Этап 3 — Прогресс (localStorage) + завершение + Активность
```
Прочитай в README.md про localStorage и streak.

1. utils/storage.js — обёртка над localStorage (get/set с try-catch, ключ приложения).
2. hooks/useLocalProgress.js — чтение/запись прогресса по схеме
   { completedWorkouts, streak, lastCompletedDate, onboarding }, пересчёт streak
   (подряд идущие дни).
3. WorkoutComplete.jsx — экран завершения: поздравление, сохранение завершённой
   тренировки, пересчёт и показ текущего streak. Бейдж за первую тренировку — опционально.
4. Подключи StreakBadge.jsx в шапку каталога (🔥 + число дней).
5. Activity.jsx (/activity): число тренировок всего, текущий streak, история последних
   завершённых. Всё только из localStorage.
```
