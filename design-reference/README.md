## Контекст проекта

Делаем упрощённое приложение домашних тренировок. Этап A — Web MVP:
- **без бэкенда, без регистрации, без личного кабинета, без подписки**;
- весь контент тренировок — статический JSON в проекте;
- прогресс пользователя — в localStorage;
- стек: React + Vite + Tailwind + React Router;
- дальше (не сейчас): Telegram Mini App, затем PWA / Android.

## Главный вывод из разбора 3 приложений

Все три приложения независимо используют ОДНУ И ТУ ЖЕ механику. Это индустриальный
стандарт, на него опираемся:

1. **Онбординг-квиз** (пол, цель, уровень, инвентарь, замеры...) → у всех троих это
   длинная маркетинговая воронка для продажи ПОДПИСКИ. У Nike короткая, у Freeletics
   средняя (вокруг ИИ-тренера Coach), у LEAP очень длинная (30+ экранов, прогнозы веса,
   отзывы, "до/после").
2. **Каталог тренировок** — лента подборок по категориям/темам, карточки с превью,
   длительностью, уровнем. Часто с индикатором streak (серия дней 🔥) в шапке.
3. **Детальная страница тренировки** — метаданные (время, уровень, инвентарь) +
   тренировка разбита на **БЛОКИ** (Разминка → Основная часть → Заминка).
4. **Плеер выполнения** — упражнение с таймером/счётчиком на весь экран → экран отдыха
   → следующее упражнение → ... → экран завершения со streak и наградой.
5. **Многонедельные программы / Journey / челленджи** — планы из множества тренировок
   на 4–12 недель.
6. **Монетизация** — подписка (paywall) после онбординга.

## Ключевая структура: тренировка = блоки

Самое важное для модели данных. И Nike, и Freeletics, и LEAP строят тренировку так:

```
Тренировка
 └── Блоки (секции): Разминка / Основная часть / Заминка
      ├── у блока есть счётчик повторов (repeat): 1x, 2x, 3x
      └── Элементы блока (по порядку):
           ├── Упражнение на ВРЕМЯ   (например 30 сек) + инструкция по технике
           ├── Упражнение на ПОВТОРЫ (например 8x / 15 повт.) + инструкция
           └── Отдых (rest)          (например 10 сек) — отдельный элемент списка
```

Все длительности храним В СЕКУНДАХ, форматируем на экране ("30 сек", "1:00 мин").
У упражнения бывают уточнения к технике ("только на левую сторону", "с чередованием ног").

## Что БЕРЁМ в MVP

- Каталог тренировок: категории → карточки тренировок (превью, название, длительность, уровень).
- Простые категории-темы, дружелюбные новичку: "<10 минут", "Всё тело", "Растяжка",
  "Без инвентаря", "Бодрое утро" и т.п.
- Быстрый выбор по уровню: Новичок / Продолжающий / Продвинутый.
- Детальная тренировка с БЛОЧНОЙ структурой (Разминка/Основная/Заминка).
- **Плеер выполнения** (сердце MVP): отсчёт "Приготовьтесь 3-2-1" → упражнение с таймером
  (для timed) или счётчиком подходов (для reps) → экран отдыха с "+сек" и "Пропустить" →
  прогресс "Упражнение N/всего" → экран завершения.
- Экран завершения с поздравлением + **streak** (серия дней) из localStorage.
- Индикатор streak 🔥 в шапке каталога.
- Нижний **таб-бар** (стандарт навигации у всех): в MVP — 3 раздела (см. ниже).
- Текстовые инструкции к упражнениям (БЕЗ видео) — Freeletics подтверждает, что
  "Способ выполнения" текстом работает как база.
- Лёгкий локальный онбординг из 2–3 вопросов (цель / уровень / инвентарь) → localStorage
  → простая фильтрация каталога. БЕЗ маркетинговой воронки.
- Мобильный стиль: чистый, крупная типографика, скруглённые кнопки, mobile-first.
  Светлая тема (по образцу LEAP) проще в вёрстке и дружелюбнее — базовый кандидат.

## Что НЕ берём в MVP (фаза 2/3 или никогда)

- ❌ Длинный онбординг-квиз с прогнозами веса, "до/после", отзывами — это воронка
  продажи подписки. Нам не нужна.
- ❌ Подписка, paywall, оплата, App Store — приложение бесплатное, бэкенда нет.
- ❌ Регистрация / вход / личный кабинет / синхронизация между устройствами.
- ❌ Многонедельные программы / Journey / челленджи (28/30 дней, "Недели 1–4...") —
  требуют логики расписания и прогресса по неделям. Фаза 2. Модель данных заложить
  на будущее, но экраны не делать.
- ❌ ИИ-подбор тренировок / виртуальный тренер Coach / выбор гида-тренера (KEVIN/KELLY).
- ❌ Custom Workout Creator (конструктор тренировок) — фаза 2/3.
- ❌ Видео-демонстрации упражнений (хостинг/CDN) — только текст в MVP.
- ❌ Музыка/плейлисты по BPM.
- ❌ Push-напоминания о тренировках (нужен сервис уведомлений).
- ❌ Landscape (горизонтальный) режим плеера — только портрет в MVP.
- ❌ Сложная система целей по серии (7/20/30/60 дней) — в MVP просто показываем текущий streak.
- ❌ Диалог удержания "Зачем сдаваться?" — упрощаем до "Выйти / Продолжить".
- ❌ Диаграмма работающих мышц, награды-ачивки (кроме, опционально, простого бейджа
  за первую тренировку в localStorage).
- ❌ Поиск по каталогу — можно отложить, пока контента мало.

## Навигация (таб-бар) в MVP — 3 раздела

Референсы: Nike (Главная·Тренировки·Активность·Программы), LEAP (Личное·Классика·Поиск·За день·Я).
У них много разделов из-за логина/программ/поиска. Нам на старте достаточно:

1. **Тренировки** — каталог (главный экран).
2. **Активность** — прогресс: число тренировок, streak, история (всё из localStorage).
3. **Профиль** — результаты локального онбординга (цель/уровень/инвентарь), настройки.

"Программы", "Поиск", "Классика" добавим по мере роста контента.

## Как использовать скриншоты

- Экран каталога → см. nike-training-club (trenirovki-glavnaya), trenirovki-doma (klassika-katalog).
- Детальная тренировка с блоками → nike-training-club (workout-detail-struktura, workout-detail-viit).
- Плеер выполнения (таймер + отдых) → trenirovki-doma (workout-player-vypolnenie,
  workout-player-otdyh-landscape). ЭТО ГЛАВНЫЙ РЕФЕРЕНС для экрана выполнения.
- Экран завершения + streak → trenirovki-doma (workout-zavershenie-nagrady-streak).
- Стиль/оформление → freeletics (тёмная тема, синий акцент), trenirovki-doma (светлая тема).
- Таб-бар → nike-training-club (tab-bar-navigation), trenirovki-doma (tab-bar-menu).

Скрины онбординга и подписки — НЕ реализуем, они здесь только для понимания
бизнес-модели конкурентов.
